# HprStudio
Dark, click-to-configure GUI for Hyprland. Style Hyprland, Waybar and your launcher (Rofi, Wofi, Fuzzel or the built-in L Launcher) with presets and live preview, record keybinds, set workspaces, download wallpapers and cursors, theme Kitty and fix config errors - with automatic backups. Python + PySide6.
